# git

个人 Git 仓库，用于存放和管理项目代码。

## 克隆

```bash
git clone https://github.com/XiHuanXueJie555/git.git
cd git
```

## 目录结构

```
.
├── .gitignore   # Git 忽略规则
└── README.md    # 项目说明
```

## 常用命令

```bash
# 查看当前状态
git status

# 暂存并提交改动
git add .
git commit -m "描述本次改动"

# 推送到 GitHub
git push
```
